# Frame Drum CNC / Jig Setup Sheet

## Scope

Pre-CAM plan for templates, bending forms, and optional laminated hoop pieces.
No verified G-code is included.

## Operations

1. Cut FD-16 bending form disks from MDF or plywood.
2. Cut diameter and bearing-edge check templates.
3. Optional: cut stave-angle setup blocks or CNC-laminated ring segments.
4. Deburr templates and verify OD/ID with tape or calipers.

## Release Checks

- Stock fits machine envelope.
- Hold-down leaves no loose inner circles during final profile pass.
- Bit radius can cut all inside corners or drawings include relief.
- Template diameter is verified before bending real hoop stock.
